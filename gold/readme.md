# Gold Layer

## Overview

The Gold layer provides business-ready analytical datasets by transforming curated Silver layer data into reporting tables for healthcare analytics.

## Gold Tables

### Patient Analytics

Combines patient and insurance information to create a business-ready patient dimension while removing sensitive personal information.

### Provider Analytics

Combines provider, hospital, and specialty information to provide provider-level analytical insights.

### Hospital Summary

Generates hospital-level KPIs including:

- Total Providers
- Average Provider Experience
- Total Departments

### Insurance Summary

Generates insurance-level analytics including:

- Total Patients
- Average Patient Age
- Male/Female Distribution
